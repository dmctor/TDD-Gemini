REGLAS DE NEGOCIO APLICABLES

RN-13. El registro exige descripcion, precio, codigo de pago y operador seleccionado.
La descripcion y el codigo de pago se almacenan sin espacios en los extremos. El precio
debe ser un numero mayor que cero; un valor no numerico o menor o igual a cero invalida
el formulario y no se envia la solicitud.
RN-14. El codigo 201 indica registro exitoso; el 409 indica que el servicio ya existe;
cualquier otro codigo se trata como error de registro.
RN-15. Normalizacion de errores de la capa de datos.

HISTORIA DE USUARIO

HU-07 — Registrar un nuevo servicio ISP

Criterios de aceptacion:
1. Dado un formulario con descripcion, precio, codigo de pago y operador validos, cuando se valida, entonces el formulario se considera valido.
2. Dado un formulario con la descripcion vacia, cuando se valida, entonces el formulario es invalido y no se envia la solicitud.
3. Dado un formulario sin operador seleccionado, cuando se valida, entonces el formulario es invalido.
4. Dado un precio con el valor abc, cuando se valida, entonces el formulario es invalido y se informa que el precio debe ser numerico.
5. Dado un precio con el valor 0, cuando se valida, entonces el formulario es invalido porque el precio debe ser mayor que cero.
6. Dado una descripcion con espacios en los extremos, cuando se construye el servicio, entonces se almacena sin dichos espacios.
7. Dado una respuesta 201 del servicio de registro, cuando se registra el servicio, entonces la operacion se considera exitosa.
8. Dado una respuesta 409 del servicio de registro, cuando se registra el servicio, entonces se informa que el servicio ya existe.
9. Dado un fallo de red durante el registro, cuando se registra el servicio, entonces se obtiene un error con codigo 500 y no se interrumpe la aplicacion.
