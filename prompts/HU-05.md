## Ampliacion: periodo de facturacion (RN-17)

Al redactar las pruebas de esta historia quedo en evidencia que el criterio 1
no era verificable, porque la especificacion no definia que es "el periodo".
Se incorporo la regla siguiente y se envio una segunda solicitud.

```
CONTRATO BAJO PRUEBA

class InvoicePeriod {
  final int year; final int month;
  String get label; // 'Marzo 2025'
}

class InvoicePeriodResolver {
  InvoicePeriod periodOf(Invoice invoice);
  List<InvoicePeriod> availablePeriods(List<Invoice> invoices);
  InvoicePeriod? activePeriod(List<Invoice> invoices);
  List<Invoice> filterByPeriod(List<Invoice> invoices, InvoicePeriod period);
}

class InvoiceItemMapper {
  List<InvoiceItem> map({
    required List<Invoice> invoices,
    required List<IspService> services,
    Map<int, String> ispNames,
  });
}

REGLA DE NEGOCIO

RN-17. El periodo de facturacion de una factura queda determinado por el anio de
su fecha de emision y por su mes de facturacion. Los periodos disponibles son los
distintos periodos presentes en las facturas consultadas, ordenados del mas
reciente al mas antiguo y sin repetirse. El periodo activo por defecto es el mas
reciente. La consulta de servicios a facturar muestra unicamente las facturas del
periodo seleccionado. Una factura cuyo servicio no exista en la lista consultada
se omite (RN-04).

CRITERIOS DE ACEPTACION

1. Dado una factura emitida en 2025 con mes de facturacion 3, cuando se determina
   su periodo, entonces el periodo es marzo de 2025.
2. Dado un conjunto de facturas con periodos repetidos, cuando se listan los
   periodos disponibles, entonces cada periodo aparece una sola vez.
3. Dado facturas de periodos distintos, cuando se listan los periodos, entonces se
   ordenan del mas reciente al mas antiguo.
4. Dado un conjunto de facturas, cuando se determina el periodo activo, entonces
   corresponde al mas reciente.
5. Dado que no hay facturas, cuando se determina el periodo activo, entonces no hay
   periodo activo y la lista de servicios queda vacia.
6. Dado un periodo seleccionado, cuando se filtran las facturas, entonces solo se
   conservan las de ese periodo, distinguiendo el mismo mes de anios distintos.
7. Dado una factura no facturada, cuando se construye el servicio, entonces su
   estado es pendiente; si ya fue facturada, su estado es facturado.
8. Dado un cambio de periodo, cuando se recarga la lista, entonces la seleccion
   previa queda vacia.
```
