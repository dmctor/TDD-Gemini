HU-01 — Autenticar administrador

Criterios de aceptacion:
1. Dado un usuario y una contrasena validos, cuando se solicita la autenticacion, entonces se obtiene un token de sesion y la lista de proveedores asociados.
2. Dado un usuario valido con contrasena incorrecta, cuando se solicita la autenticacion, entonces no se genera sesion y se obtiene un error de credenciales.
3. Dado un formulario con el usuario vacio, cuando se intenta autenticar, entonces no se envia la solicitud y se informa que los campos son obligatorios.
4. Dado un usuario con espacios en los extremos, cuando se solicita la autenticacion, entonces se envian las credenciales sin dichos espacios.
5. Dado un fallo de red durante la autenticacion, cuando se solicita la autenticacion, entonces se obtiene un error con codigo 500 y no se interrumpe la aplicacion.
6. Dado una autenticacion exitosa, cuando finaliza el proceso, entonces el token queda almacenado bajo la clave jwt_token.
